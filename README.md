# Oracle Fusion HCM – OTBI & BI Reporting Project

## 📌 Project Overview

This repository showcases Oracle Fusion HCM Reporting and Analytics implementations using:

- Oracle Transactional Business Intelligence (OTBI)
- BI Publisher (BIP)
- Dashboards & Analytics
- Data Models & SQL Queries
- Report Bursting
- Security & Scheduling
- Fusion HCM Reporting Architecture

The project demonstrates end-to-end report development in Oracle Fusion HCM including report creation, subject area analysis, SQL-based reporting, bursting configurations, dashboards, report scheduling, and data extraction mechanisms.
